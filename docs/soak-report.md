# 长运行稳定性与保存链压测报告

| 项 | 值 |
|---|---|
| 日期 | 2026-10-07 ~ 08 |
| 对象 | 酒馆安卓移植版 v1.1.0（x86_64 debug 变体） |
| 环境 | Android 16 模拟器（AEHD 硬加速，2.5GB RAM，3 核，8GB 宿主机——最弱基准） |
| 时长 | 约 22 分钟连续运行 |
| 负载 | 每 20s HTTP 探活；每 90s 一次 /api/chats/save 写压测（消息数 100→660 递增）；全程采样 node/proot/App 内存 |
| 脚本 | `scripts/soak_test.sh` |

## 结果

### 可用性：58/58 探活全部 HTTP 200（100% 在线，零中断）

### 保存链延迟（报告《发热归因》§3 指出的第一热路径）

| 消息数 N | 保存耗时 | 说明 |
|---|---|---|
| 100 | 49 ms | |
| 220 | 53 ms | |
| 380 | 43 ms | |
| 420 | 69 ms | |
| 620 | 59 ms | |
| 660 | 56 ms | 数据量 6.6× 增长 |

**结论：延迟随聊天规模基本持平（43~69ms 带内）**。对照改造前机制（每次保存 = 临时文件写 N + fsync 刷盘 + rename 垫片 copy 2N + 10s 节流全量备份再一份），现在的服务端保存路径已砍掉 fsync 与备份两份大头。

### 内存（22 分钟）

| 进程 | 起 | 终 | 漂移 |
|---|---|---|---|
| node | 374.5 MB | 376.5 MB | +2.0 MB |
| proot | 3.4 MB | 3.4 MB | 0 |
| App (WebView) | 237.5 MB | 238.8 MB | +1.3 MB |

**无泄漏迹象**（漂移含压测数据本身持有的 660 条消息）。

### 温度

模拟器无真实热区传感器（thermal_zone 无数据），温度项以真机为准；本机 CPU 占用在测试全程稳定（探活 200 且无超时）。

## 复现

```bash
# 设备端已运行 ST（adb forward tcp:18000 tcp:8000）后：
WORK=./soak-out ROUNDS=60 bash scripts/soak_test.sh
```
